🏏 IPL Data Analytics Dashboard | Power BI Project
📌 Project Overview

This project is an interactive Data Analytics Dashboard built using Power BI, based on historical Indian Premier League (IPL) data.
The dashboard converts raw cricket data into meaningful insights related to team performance, match outcomes, and season-wise trends.

The project demonstrates end-to-end data analytics skills, including data cleaning, data modeling, DAX calculations, and dashboard storytelling.

🎯 Project Objective

Analyze IPL team performance across multiple seasons

Identify winning trends and consistency patterns

Compare teams based on matches played and wins

Build an interactive and user-friendly dashboard for analysis

📊 Dashboard Features

Team-wise performance analysis

Season-wise comparison of matches and wins

KPI cards for quick insights

Interactive slicers for team and season selection

Clean and easy-to-understand visualizations

⚙️ Data Preparation & Modeling

Cleaned and transformed raw data using Power Query (ETL)

Handled missing values and corrected data types

Created relationships between multiple tables

Built calculated measures using DAX

🛠️ Tools & Technologies Used

Power BI Desktop

Power Query

DAX (Data Analysis Expressions)

Data Visualization & Storytelling
